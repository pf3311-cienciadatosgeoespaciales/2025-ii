# Tarea 03 - Desarrollo de aplicaciones geoespaciales interactivas básicas

## Fecha de entrega

La fecha y hora límite para la entrega de esta tarea es **viernes 14 de noviembre de 2025 a las 23:59**.

## Objetivos

Cada estudiante debe mostrar que es capaz de:

- Desarrollar aplicaciones interactivas básicas con la biblioteca Streamlit que incluyan visualizaciones en formato de tablas, gráficos estadísticos y mapas.
- Publicar aplicaciones Streamlit en la plataforma Streamlit Cloud.

## Entregables

- Dirección de un repositorio en GitHub con el código y (si es necesario) los datos de la aplicación Streamlit.
- Dirección de la aplicación publicada en Streamlit Cloud.

**Debe entregar tanto el repositorio con el código fuente como la aplicación publicada**. La entrega debe realizarse a través de la plataforma Mediación Virtual.

## Desarrollo

Para el conjunto de datos que utilizó en la anterior (y otros conjuntos adicionales, si es necesario), debe desarrollar una aplicación Streamlit que incluya:

- Una tabla interactiva.
- Un gráfico estadístico interactivo.
- Un mapa interactivo.

## Calificación

- Presentación general de la aplicación (estructura, orden, ortografía): 10%
- Tabla interactiva: 30%
- Gráfico estadístico interactivo: 30%
- Mapa interactivo: 30%

## Consideraciones adicionales

- Esta tarea puede realizarse individualmente o en parejas.
- No es necesario que agregue controles para filtrar los datos (esto se hará en el proyecto final). La tabla, el gráfico y el mapa pueden basarse en el conjunto de datos completo o en un subconjunto "fijo".
